# cd-personal-website

Personal site for Charlotte Demas, built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```

## Editing

- **Text** (experience, projects, skills, education, summary): `lib/content.ts`
- **Layout & section order**: `app/page.tsx`
- **Colors & fonts**: the `@theme` block in `app/globals.css`
- **Photo & resume**: `public/charlotte.jpg`, `public/Charlotte-Demas-Resume.pdf`

## Deploy

Pushed to `main` → deployed automatically by Vercel.
